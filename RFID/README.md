# M7E Hecto RFID 리더 사용 방법 (& HangerWay)

SparkFun Simultaneous RFID Reader - M7E Hecto를 라즈베리파이에 연결해 의류 UHF RFID 태그를 읽는 테스트 코드이다. 외부 안테나 없이 보드에 붙은 PCB 안테나만 쓰고, 출력(Read Power)을 조절해 인식 거리를 맞춘다.

이 코드는 테스트용 베이스 코드이다. 테스트 결과나 로봇 구성에 따라 필요한 부분을 수정하거나, 이 코드를 바탕으로 새 코드를 추가로 만들어 사용할 수 있다.

## 파일

- `m7e_power_read.py`: 리더 연결, 연속 읽기, 출력 조절, RSSI 필터, 출력 스윕 기능

## 준비

1. 보드 UART 스위치를 USB로 두고, USB-C 케이블로 라즈베리파이에 연결한다.
2. 장치가 인식됐는지 확인한다. `/dev/ttyUSB0`이 보이면 된다.
   ```bash
   ls /dev/ttyUSB*
   ```
3. pyserial이 설치되어 있는지 확인한다. 오류가 나면 설치한다.
   ```bash
   python3 -c "import serial"
   sudo apt install -y python3-serial
   ```

GPIO UART로 연결할 때는 보드 스위치를 SER로 두고, raspi-config에서 Serial Port를 켠 뒤(login shell No, hardware Yes) `--port /dev/serial0`으로 실행한다. 파이와 보드의 GND는 공통으로 연결한다.

## 실행

```bash
python3 m7e_power_read.py                               # 기본: /dev/ttyUSB0, 10 dBm
python3 m7e_power_read.py --power 1500 --rssi -60       # 시작 출력 15 dBm, RSSI -60 이하 무시
python3 m7e_power_read.py --port /dev/serial0           # GPIO UART 연결
```

명령어를 입력하고 Enter를 누르면 실행 중에 바로 적용된다. 출력 단위는 0.01 dBm이다(1500 = 15.00 dBm).

- `p<값>`: 출력 설정 (예: `p1500`)
- `+` / `-`: 출력을 1 dBm씩 올리기 / 내리기
- `r<값>`: RSSI 임계값 설정 (예: `r-60`), `r`만 입력하면 해제
- `l<값>`: 출력 상한 변경 (기본 2200, 최대 2700)
- `s`: 읽기 시작 / 정지
- `c`: 출력 스윕 (0 dBm부터 상한까지 1 dBm씩 올리며 인식 횟수와 RSSI를 표로 출력)
- `?`: 현재 설정 보기
- `q`: 종료

출력 예:

```
RSSI[-58] PWR[10.00 dBm] EPC[E2 80 11 70 00 00 02 0A 1B 2C 3D 4E]
```

## 주의 사항

- 내장 안테나는 인식 거리가 몇 cm 수준이다. 처음에는 태그를 안테나 면 가까이 대고 테스트한다.
- 22 dBm을 넘게 쓸 때는 리더에 별도 5V(1A 이상) 전원을 연결한다. USB 전원만 쓰면 전압이 떨어질 수 있다.
- 높은 출력으로 오래 쓰면 모듈이 뜨거워져 출력이 자동으로 제한된다. 필요한 만큼만 출력을 쓴다.
- 전압 저하 여부는 `vcgencmd get_throttled`로 확인한다. `0x0`이면 정상이다.
- 실행이 끝나면 `q`로 종료해야 재실행 때 연결 오류가 덜 난다.

## 테스트 목록

완료한 항목은 `[ ]`를 `[x]`로 바꿔 진행 상황을 표시한다.

- [x] 1. 연결 확인: 리더 연결, 태그 1개 인식, EPC가 맞게 출력되는지 확인
- [ ] 2. 거리-출력 측정: 태그를 1, 2, 3, 5, 7, 10cm에 두고 각각 `c` 스윕을 실행해 안정적으로 읽히는 최소 출력과 RSSI 기록
- [ ] 3. 태그 방향: 태그를 정면, 옆면, 비스듬히 두었을 때 인식 거리와 RSSI 차이 확인
- [ ] 4. 의류 조건: 옷감 종류(얇은 옷, 두꺼운 옷)와 옷걸이 재질(금속, 플라스틱)에 따른 인식 변화 확인
- [ ] 5. 인접 태그 구분: 대기 행거에 옷 여러 벌을 걸고 가장 가까운 옷 하나만 읽히는 출력과 RSSI 임계값 조합 찾기
- [ ] 6. 회전 중 인식: 대기 행거를 회전시키면서 각 옷의 태그가 놓치지 않고 읽히는지, 인식까지 걸리는 시간 측정
- [ ] 7. 리더 장착 위치: 그리퍼가 옷을 잡는 위치 바로 옆에 고정했을 때 행거봉과 간섭 없이 인식되는지 확인
- [ ] 8. 전원 확인: 사용할 출력에서 `vcgencmd get_throttled` 값이 바뀌지 않는지 확인
- [ ] 9. 장시간 동작: 사용할 출력으로 30분 이상 연속 읽기를 하며 발열과 온도 제한 메시지 확인
- [ ] 10. 로봇 코드 연동: `M7E` 클래스를 가져와 "행거 회전 → 태그 인식 → 목적지 판단" 흐름에 연결

## 측정 기록 양식 (2번 테스트용)

```
거리(cm) | 최소 인식 출력(dBm) | 평균 RSSI | 최대 RSSI | 비고
```
