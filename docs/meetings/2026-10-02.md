## 1. 전체 구조 및 설계 방향

- 로봇은 의류를 보관·정렬하고, 목적지 행거로 이송하여 재진열하는 구조를 검토한다.
- 로봇 내부에서는 의류를 종류별로 분류하지 않고, 보관·정렬하는 역할을 우선한다.
- 대학생 캡스톤 수준에서 구현할 수 있도록 **모터 수, 구동축 수, 제작 비용과 제어 난도를 줄이는 방향**을 고려한다.
- 옷걸이만 움직이는 상황이 아니라 실제 옷이 걸린 상태를 기준으로 **의류의 폭·길이·무게와 옷끼리의 간섭**을 확인한다.
- 대기 행거와 도킹하여 옷을 이송하는 방식과 행거 모듈 전체를 교환하는 방식을 비교한다.

## 2. 행거 형태 및 로봇 결합 구조

### 행거 형태

- **후보:** 일자형 / 원형 / 달팽이형
- 제한된 공간에 여러 벌을 보관하기 위해 원형 행거를 검토한다.
- 옷이 한 지점에 겹치는 문제를 줄이기 위해 **지지대 길이를 달리한 달팽이형 배치** 또는 **달팽이형 경로**를 검토한다.
- 원뿔형 배치, 가장 긴 지지대의 길이와 지지축 위치, 저장된 의류를 꺼내는 순서도 고려한다.
- 달팽이형은 무게가 비대칭으로 배치될 수 있으므로 무게중심과 지지 안정성을 확인해야 한다.

### 로봇 결합 방식

- **후보:** 모듈형 / 내장형 / 절충안

| 로봇 배치 | 장점 | 단점 및 검토 방향 |
| --- | --- | --- |
| 행거 한쪽에 부착 | 전체 폭과 부피를 줄일 수 있음 | 무게중심 확보와 주행 안정성 검토 |
| 행거를 감싸는 형태 | 행거를 여러 위치에서 지지할 수 있음 | 전체 크기가 커져 후순위로 검토 |
- 현재는 **로봇 내장형 원형 행거와 한쪽에 부착한 이송 장치**를 우선 검토한다.
- 달팽이형의 가장 돌출된 끝까지 양쪽에서 지지하면 로봇 폭도 함께 커질 수 있다.
- 매장 벽의 위치와 ㄱ자 배치를 고려하고, 행거 길이와 동작 범위만큼 공간을 확보해야 한다.

## 3. 옷걸이 파지 및 이송 방식

### 이송 방식 후보

- 슬라이딩·푸시 방식
- 후크·포크 방식
- 그리퍼 방식
- 도킹과 슬라이딩을 결합한 이중 구조

로봇 상부에 슬라이딩 가능한 레일을 배치하여 옷걸이를 필요한 위치로 이동시키는 방안을 검토한다. 필요한 경우 Z축 회전을 추가하되, 구동축 증가에 따른 모터 수와 제어 난도를 고려한다.

### 옷걸이를 잡는 방법

옷의 몸통보다 **옷걸이 고리 또는 후크 바로 아래 목 부분**을 이용하여, 옷이 아래로 늘어진 상태를 유지하는 방향을 우선한다.

| 방식 | 동작 | 검토 사항 |
| --- | --- | --- |
| 고리 아래 받침형 | 받침이 고리 아래로 진입하여 들어 올림 | 집게 개폐 없이 지지·이송 가능한지 확인 |
| U/V자 포크형 | 포크가 고리 또는 목 부분을 받아 들어 올림 | 위치 정렬과 이송 중 이탈 가능성 확인 |
| 목 부분 그리퍼형 | 목 부분을 양쪽에서 잡아 이동 | 개폐 구동과 파지 안정성, 회전 시 헛돎 검토 |
- 후크 형상은 판 형태 또는 갈고리 두 개를 사용하는 방안을 검토한다.
- 끝부분에 그리퍼가 필요한지, 목 부분을 회전시키는 별도 모터가 필요한지 확인한다.

### 옷걸이 표준 인터페이스

옷걸이 규격 변경을 최소화하는 방향과, **목 부분에 로봇이 잡는 표준 인터페이스를 추가하는 방향**을 비교한다.

표준 인터페이스를 적용할 경우 다음 조건을 충족해야 한다.

1. 대기 행거의 홈에 옷걸이 위치가 고정될 것
2. 로봇이 항상 같은 위치를 잡을 수 있을 것
3. 기존 매장 봉에 일반 옷걸이처럼 걸 수 있을 것

## 4. 옷걸이 위치 정렬 및 식별

옷걸이 자체를 특정 규격으로 제한하는 대신, 행거 구조를 통해 옷걸이가 일정한 위치에 머물도록 하는 방안을 검토한다.

| 구성 요소 | 역할 |
| --- | --- |
| 홈·슬롯 | 옷걸이 위치 정렬 및 고정 |
| 스위치 | 해당 위치의 옷걸이 존재 여부 확인 |
| RFID | 개별 의류 또는 옷걸이의 ID 확인 |
- 위치 정렬, 점유 여부 확인, 개별 ID 인식은 서로 다른 기능으로 구분한다.
- 핵심 동작에 필요한 기능을 판단한 뒤 적용 여부를 결정한다.

## 5. 도킹 및 원형 행거 회전 구조

### 도킹 위치와 구동부 배치

- 원형 행거 중앙을 도킹 또는 구조물 결합 공간으로 사용하는 방안을 검토한다.
- 중앙 도킹 공간과 간섭하지 않도록 모터와 구동부를 외곽에 배치하는 방향을 고려한다.
- 중앙 베어링 또는 외곽 지지롤러로 행거를 지지하고, 외곽 기어와 피니언으로 회전력을 전달하는 구조를 검토한다.
- 회의에서 언급한 랙·피니언 구상은 실제 회전 구조에 맞춰 기어 형상과 결합 방법을 구체화한다.

### 외곽 기어 구동 방식

- 원형 행거의 외곽 전체 또는 일부에 톱니를 형성하고, 로봇의 작은 피니언으로 회전시키는 방식이다.
- 모듈형에 적용하면 교환 가능한 행거와 구동 모터를 분리할 수 있다.
- **행거와 의류의 하중은 베어링·롤러가 지지하고, 모터는 회전을 담당하도록 역할을 분리**한다.
- 모터 선정 시 마찰, 회전 가속, 무게 불균형에 따른 영향을 확인해야 한다.
- 빠른 회전이 필요하지 않으므로 저속·고토크 감속모터 적용을 검토한다.

### 지지 구조 비교

| 구조 | 행거 지지 | 회전 구동 | 교환 방식 | 검토 사항 |
| --- | --- | --- | --- | --- |
| 중앙 허브 + 외곽 기어 | 중앙 베어링 | 외곽 피니언 | 중앙 허브 분리 | 중앙 결합부와 도킹 공간의 간섭 |
| 외곽 롤러 + 외곽 기어 | 둘레의 여러 지점 | 외곽 피니언 | 측면 분리 검토 | 롤러 배치 공간과 지지 안정성 |
| 양끝 지지 | 행거 양끝 | 중앙 또는 외곽 구동 | 양끝 결합 해제 | 행거 길이에 따른 로봇 폭 증가 |

## 6. 옷걸림 방지 및 재진열 과정

![image.png](assets/2026-10-02/clothing-interference-review.png)

- 의류가 구조물이나 다른 옷에 걸리지 않도록 이송 경로를 검토한다.
- 옷걸림을 줄이기 위해 내장 행거의 형태와 옷걸이 간격을 조정하는 방안을 고려한다.
- 옷걸이를 상하 방향으로 들어 올리고 내릴 때 필요한 공간과 간섭을 확인한다.
- 진열된 옷 사이에 공간을 만드는 방법으로 **뾰족한 삼각형 구조, 푸셔 또는 그리퍼**를 검토한다.
- 공간을 벌리는 기능과 옷걸이를 잡는 기능을 하나의 장치로 수행할 수 있는지 확인한다.
- 목적지 행거 자체의 형태는 이번 검토 범위에서 제외하되, 재진열에 필요한 접근 공간과 연결 동작은 고려한다.

## 7. 대기 행거 및 모듈 교환 문제

모듈형 수거 방식을 적용할 경우, 로봇이 기존 행거를 가지고 있는 상태에서 새로운 대기 행거를 어떻게 장착할지가 핵심 설계 문제이다.

- 탈의실 측에 **기존 행거 반납용 슬롯과 수거용 대기 행거 슬롯**을 마련하는 방식
- 행거 전체 또는 봉을 탈착 가능한 모듈로 구성하는 방식
- 의류가 걸린 대기 행거와 빈 대기 행거를 교환하는 방식

기존 행거를 내려놓는 위치, 새 행거를 장착하는 순서, 교환에 필요한 공간과 고정 방법을 함께 검토한다.

## 9. 회의 후 자문 및 추가 의견

- 교수님 자문으로, 로봇팔 두 개가 삼각형 부분을 잡아 들어 올린 뒤 옆으로 옮기는 방식이 제안되었다.
- 그리퍼로 잡아 회전시키는 방식은 헛돌 가능성이 있어 추가 피드백과 검증이 필요하다는 의견이 있었다.
- 초기에는 3D 프린팅으로 구조와 동작을 시험하고, 이후 개선하는 방향이 제안되었다.
- 실제 로봇팔을 사용하는 방안도 언급되었으며, 현재 구상과 제작 비용·구현 난도를 비교할 필요가 있다.
- 의류 처리 동작뿐 아니라 이동 거리의 최적화도 검토 요소로 언급되었다.
- 추가 검토 대상으로 ‘다이나믹스 로봇팔’이 언급되었다.

## 10. 현재 검토 방향

| 구분 | 현재 방향 |
| --- | --- |
| 행거 | 로봇 내장형 원형 행거 우선 검토, 달팽이형 배치 구체화 |
| 이송 장치 배치 | 로봇팔 사용을 지양하는 방향 |
| 의류 이송 | 상부 슬라이딩 레일과 그리퍼·후크·포크 조합 비교 |
| 옷걸이 파지 위치 | 고리 또는 목 부분 이용 |
| 회전 | 중앙 도킹 공간을 확보하고 외곽 기어 구동 검토 |
| 하중 지지 | 중앙 베어링 또는 외곽 지지롤러 비교 |
| 미정 사항 | 행거 결합 방식, 구동축 수, 파지 장치 형상, 구체적인 이송 동작, 모듈 교환 및 목적지 행거와의 연결 방식 |

로봇 내장형 원형 행거를 우선 검토하며, 의류 간 간섭을 줄이기 위한 달팽이형 배치를 구상하였다. 행거 한쪽에 슬라이딩 레일과 파지 장치를 배치하여 의류를 이송하고, 중앙 도킹 공간과 간섭하지 않는 외곽 회전 구동 구조를 고려하고 있다. 각 구조의 적용 여부는 추가 비교와 동작 검증을 통해 결정한다.
