## 1. 회의 목표 및 진행 사항

- 제작에 필요한 **부품 주문 시작**
- 그리퍼와 로봇 본체, 목적지 행거의 구조 및 크기 검토
- 의류 식별을 위한 RFID·NFC 방식과 관련 부품 조사
- 중간 보고서 제출 일정 및 작성 내용 확인
- **이번 학기 내 그리퍼 및 본체 구조 확정**을 주요 목표로 설정

## 4. 기구 구조 및 치수 검토

| 항목 | 논의 내용 | 확인 사항 |
| --- | --- | --- |
| **랙·피니언** | 길이 60 이상으로 검토 | 단위 및 최종 길이 확인 필요. 그리퍼 무게와 구조가 확정된 후 세부 사양 결정 |
| **로봇 본체** | 높이 약 150cm × 폭 약 85cm, 깊이 미정 | 높이 약 130cm의 행거보다 높게 설계할 필요가 있음 |
| **밑판** | 지름 약 75cm | 밑판 크기를 고려하여 본체 폭을 약 85cm로 검토 |
| **목적지 행거** | 창종설 때 사용했던 난간 활용 검토 | 높이 약 120cm로 추정되며 실측 필요 |
| **원형 행거 창살 고정** | 철심을 박고 3D 프린팅 부품으로 감싼 뒤 틈을 마감하는 방식 검토 | 결합부의 강도와 고정 방법 확인 필요 |
| **용접** | 용접 활용 및 장비 대여 가능 여부 논의 | 필요 여부와 이용 방법 추가 확인 |

## 5. 제어 및 의류 식별 방식 조사

**제어 보드**

- 라즈베리 파이 사용 방향 논의

**UHF RFID**

- Chafon, YR903 및 R200 관련 제품·자료 조사
- 제품 설명에 기재된 인식 거리, 출력, UART 통신 지원 여부 등을 비교
- R200의 장거리 인식 및 가격 표기는 추가 확인 필요
- EPC를 이용한 태그 식별, 여러 태그 동시 인식, 태그 데이터 읽기·쓰기 가능 여부 조사
- 추후 보고서에 RFID 조사 내용 정리 예정

**NFC 제안**

- 그리퍼 끝부분에 NFC 리더를 장착하여 의류 태그를 읽는 방식 제안
- 짧은 인식 거리를 고려하여 리더와 태그가 가까워지는 위치 검토
- 태그를 집게가 직접 닿지 않는 옷의 목 부분에 부착하는 방안 논의
- 옷걸이에 실제 옷을 걸어 리더와 태그 사이의 거리, 방향 및 인식 가능 여부 확인 필요

| 검토 항목 | NFC | UHF RFID |
| --- | --- | --- |
| **회의에서 검토한 활용 방향** | 그리퍼 가까이에서 개별 의류 인식 | 일정 범위 내 의류 태그 인식 |
| **확인할 사항** | 태그 부착 위치와 실제 인식 거리 | 여러 태그가 읽힐 때 대상 의류를 구분하는 방법 |
| **현재 상태** | 제안 및 배치 검토 중 | 제품·통신 방식 조사 중 |

**고무패드**

- 그리퍼 접촉면의 미끄럼을 줄이기 위한 고무패드 조사
- 실제 부착 후 성능 확인 필요
